# 파일 수 표시 수정 — 2026-10-26

함수 검사 통과 항목 수를 파일 수로 표시하던 오류를 수정했다. 통과한 검사들의 상대 파일 경로를 중복 제거해 파일 수를 계산하고, 검사 항목 수는 별도로 표시한다.

예: 같은 파일에 검사 항목이 2개 있으면 `1개 파일에서 2개 항목 통과`로 표시한다. 서로 다른 폴더의 동명 파일은 별개 파일로 계산한다.

변경 후 생성되는 최종 결과·DB 결과 요약·최종 결과 파일에 적용된다. 기존에 저장된 보고서와 테스트 원본 기록은 다시 쓰지 않았다.

실제 생성 흐름을 사용하는 회귀 테스트 2개가 통과했다. 동일 파일 중복 검사 수와 서로 다른 폴더의 동명 파일 수를 확인했다.

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -p test_universal_workflow.py -k summary_counts -q
```
