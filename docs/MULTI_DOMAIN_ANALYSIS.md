# 다양한 업무의 비서실장 분석

개발, 콘텐츠, 기획·분석, 문서·사무, 데이터, 디자인, 운영·관리, 마케팅·영업을 복수 분야로 분석합니다.
로컬 모델 지침과 공통 배정 정책에 적용되며 분석 화면에 분야, 필요한 도구, 대안, 확인 질문이 표시됩니다.

`work_domains`, `tool_requests`, `clarification_questions`는 분석 결과와 함께 저장됩니다.
개발자는 코드 구현 요청에 배정하며 비개발 요청은 해당 분야의 담당 역할을 구성합니다.
라이브러리는 기존 프로젝트 의존성 목록에 연결하고 버전이 불확실하면 환경 해석 단계에 맡깁니다.
도구 요청은 준비 확인이 필요한 제안이며 설치·인증·외부 전송·과금·게시 권한을 부여하지 않습니다.
API 키나 호스트 프로그램을 자동 설치하지 않습니다. 영상 생성 API 연결과 실제 영상 검증 기능은 별도 구현이 필요합니다.

현재 규칙은 대표적인 한국어 업무 표현을 보완하는 범위입니다. 분야가 모호하거나 입력 자료·완료 기준이 없으면
분석 결과를 검토하고 확인해야 합니다. 준비 확인 필요 표시는 실행 검증 통과를 의미하지 않습니다.
